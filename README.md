# Combat Robot Builder Support Site

GitHub Pages-ready support and privacy site for Combat Robot Builder.

## Recommended repository
`combat-robot-builder-support`

## Publish with GitHub Pages
1. Create a public GitHub repository named `combat-robot-builder-support`.
2. Upload `index.html`, `privacy.html`, and `support.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the Pages deployment to finish.

Using GitHub account `t3100550-wq`, the expected URLs are:

- Support URL: `https://t3100550-wq.github.io/combat-robot-builder-support/`
- Privacy Policy URL: `https://t3100550-wq.github.io/combat-robot-builder-support/privacy.html`

## App Store Connect
Use the Support URL in the platform version metadata and the Privacy Policy URL in App Information / Privacy Policy URL where requested.
